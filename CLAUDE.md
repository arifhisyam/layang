# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Stack

- **Backend**: Laravel 13 (PHP 8.3+), Laravel Fortify (authentication), Pest (testing)
- **Frontend**: React 19, Inertia.js 3, TypeScript, Tailwind CSS v4, Vite 8
- **Special tooling**: Laravel Wayfinder (auto-generates type-safe route/action helpers), React Compiler

## Architecture

### Inertia.js Integration

This is an Inertia.js application where the backend (Laravel) and frontend (React) communicate via Inertia responses rather than traditional API calls.

- Backend controllers return `Inertia::render('page-name', $props)` instead of JSON
- Frontend pages are in `resources/js/pages/`
- Shared data is configured in `app/Http/Middleware/HandleInertiaRequests.php`

### Auto-Generated Route & Action Helpers (Wayfinder)

**Critical**: `resources/js/routes/` and `resources/js/actions/` are auto-generated by Laravel Wayfinder. Do NOT manually edit these files.

- Route helpers: `import { dashboard } from '@/routes'` gives you type-safe route URLs
- Action helpers: `import ProfileController from '@/actions/App/Http/Controllers/Settings/ProfileController'` mirrors backend controller structure
- When you add new routes or controllers, run `npm run dev` or `npm run build` to regenerate these files

### Inertia Form Pattern

Use Wayfinder-generated form helpers instead of manual fetch/axios:

```tsx
<Form {...ProfileController.update.form()}>
  {({ processing, errors }) => (
    // form fields
  )}
</Form>
```

This automatically handles CSRF tokens, method spoofing, and provides processing/error states.

### Layout System

Layouts are assigned in `resources/js/app.tsx` based on page name patterns:

- `welcome` → no layout
- `auth/*` → `AuthLayout`
- `settings/*` → `[AppLayout, SettingsLayout]` (nested)
- Everything else → `AppLayout`

Individual pages can add breadcrumbs via `PageComponent.layout = { breadcrumbs: [...] }`

### Middleware Stack

Key middleware (registered in `bootstrap/app.php`):

- `HandleAppearance` - Manages theme cookie (light/dark/system)
- `HandleInertiaRequests` - Shares props like `auth.user`, `sidebarOpen` to all pages
- `AddLinkHeadersForPreloadedAssets` - Performance optimization

## Common Commands

### Development

```bash
composer dev              # Runs Laravel server + queue + Vite concurrently
npm run dev              # Vite dev server only
php artisan serve        # Laravel dev server only
```

### Build

```bash
npm run build            # Production build
npm run build:ssr        # SSR-ready build
```

### Testing

```bash
composer test                                    # Lint + run all tests
php artisan test                                 # Run all Pest tests
php artisan test --filter=TestName               # Run specific test
php artisan test tests/Feature/Auth/LoginTest.php  # Run specific file
```

Tests use SQLite in-memory database (configured in `phpunit.xml`). Feature tests automatically use `RefreshDatabase` (configured in `tests/Pest.php`).

### Linting & Formatting

```bash
# Backend
composer lint            # Laravel Pint (auto-fix)
composer lint:check      # Laravel Pint (check only)

# Frontend
npm run lint             # ESLint (auto-fix)
npm run lint:check       # ESLint (check only)
npm run format           # Prettier (auto-fix)
npm run format:check     # Prettier (check only)
npm run types:check      # TypeScript type checking
```

### CI

```bash
composer ci:check        # Runs all frontend checks + backend tests
```

### Setup

```bash
composer setup           # Full setup: deps, .env, key, migrate, npm install/build
```

## Path Alias

Use `@/` for imports from `resources/js/`:

```tsx
import { Button } from '@/components/ui/button'
import { dashboard } from '@/routes'
```

Configured in `tsconfig.json` with `"@/*": ["./resources/js/*"]`

## Key Files

- `bootstrap/app.php` - Application bootstrap, middleware registration
- `routes/web.php` - Main routes (includes `routes/settings.php`)
- `app/Providers/FortifyServiceProvider.php` - Fortify auth configuration
- `resources/js/app.tsx` - Inertia entry point, layout assignment
- `vite.config.ts` - Vite configuration with Laravel, Inertia, React Compiler, Tailwind, Wayfinder plugins
